# AI Dataset Cleaner & Analyzer

An AI-powered web app built using Streamlit and Python to clean, analyze, and generate insights from datasets.

## 🚀 Features
- Upload CSV datasets
- Data preview and structure analysis
- Missing value detection and handling
- Outlier detection and cleaning
- AI-based insights and suggestions
- Auto-clean feature
- Download cleaned dataset

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
